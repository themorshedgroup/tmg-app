Tap a chip to select it (it turns navy). Tap again to remove.
The six KPI types: Touch Call, Follow Up Call, Notes, Hotzone Action/s, Pop-by, Lunch.
Add another KPI adds another person card (log a whole day at once). Pick Hotzone Action/s and a "number of hotzone actions" box appears.
Also on the form: a CTC Hours field, and Add other KPIs for items like Open House or Agent Training (with a count).
3
Way 2
Paste your notes
Prefer to type it fast? Choose Paste your notes and write one line. The assistant reads it and fills the form for you. Start with the date, then list each person.
6/18 // Sam Smith lunch call // John Doe hotzone // Jane Cruz pop-by notes
One line. Date first, then each person.
"call" → Touch Call · "note" → Notes · "popped by / drop by" → Pop-by · "lunch" → Lunch · "hotzone / door-knock" → Hotzone Action/s. Say "follow-up" for a Follow Up Call.
4
The key trick
The // divider
The double slash // is how you separate people. Everything between two // belongs to one person — their name plus whatever they did, in any order.
Date6/18 → June 18, 2026
PersonSam Smithlunch call → Lunch, Touch Call
PersonJohn Doehotzone → Hotzone Action/s
PersonJane Cruzpop-by notes → Pop-by, Notes
How 6/18 // Sam Smith lunch call // John Doe hotzone // Jane Cruz pop-by notes is read.
Quick rule: a // before every person. The bit before the first // is the date.
No slashes? It'll still try its best to split people and activities — but // makes it exact.
5
Finish
Match & confirm
Either way, you land on a review card. Each name is matched to a contact — pick the right one from the suggestions (or add a new contact). Once every person is linked, tap Confirm & send and it's logged.
Why match? Linking each name to the real contact is what files the KPI against the right person in the CRM.
★
Good to know
One person, many KPIs. Tap as many chips as apply (or write several activities after a name) — they all log together.
