Quick-action pills
Tap a pill to start fast
Pills are shortcuts so you don't have to type the whole request — tap one and the assistant walks you through it. Open a fresh chat and you'll see two scrolling rows of them below the greeting; once you're mid-conversation they collapse into a short row with a ⋯ for everything else.
New Chat Add To Do Add KPIs SOONDeals Update
Pills are plain black & white — a SOON badge, not a color, is what marks one as not live yet.
New Chat — always the first pill. Starts a fresh conversation so a new topic doesn't get mixed into the old one.
Add To Do — quickly capture a task. The assistant turns what you type into a to-do for you.
Add KPIs — log your weekly numbers (calls, pop-bys, notes…). The assistant collects them step by step and files them. For Sales Agents only
Today's Brief / Weekly Brief — pulls your calendar into an interactive schedule card you can RSVP from, right in the chat.
Note: Which pills you see can depend on your role — an admin may set a pill (like Add KPIs) to show only for certain roles.
Note: A few pills are marked SOON — they're on the roadmap but not wired up yet, so tapping one just says so.

3
Projects
Group chats into Projects
A project keeps all the chats for one deal or topic together — with its own instructions, memory, and files the assistant uses every time you chat inside it. Like a Claude Project.

Tap ＋ to create · tap a name to filter the list to it · ⋯ → Open / edit for its settings.
Create one: tap ＋ next to "Projects", give it a name (and optional instructions), then Create.
Open / edit (the project's ⋯) gives you:
· Instructions — how the assistant should behave here ("You're helping with 123 Main St. Always reference the seller's priorities.")
· Project memory — facts to remember (people, addresses, numbers, decisions).
· Files — text knowledge (txt, csv, md, json — up to 2 MB each) the assistant can draw on.
New chats inside a project automatically use its instructions, memory, and files. A 📁 tag shows at the top of those chats.
Delete a project: open it and tap the 🗑 trash in the top-right. The project is removed and its chats are unlinked (the chats themselves stay).
4
Assistant memory
Teach it once, for every chat
Tap the ⚙ gear at the top of the AI Chat panel to set Assistant memory — notes the assistant keeps in mind across every AI chat (not just one project).
Good things to put here: your role, who you work with, how you like replies (short vs detailed), recurring context. It's personal to you.
★
Good to know
Start fresh often. New topic? Hit New Chat so context stays clean and answers stay sharp.
Attach files with the 📎 clip in the message bar — images, PDFs, Word/PowerPoint/Excel, and plain text. For knowledge the assistant should always have, add it to a Project instead.
The assistant can hand things back too — ask for a doc, sheet, or slide deck and it can generate a real downloadable file, not just chat text.
